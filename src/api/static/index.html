THE ENGINE UNDERNEATH

Detection is a question of perspective.

Guardian combines a per-flow random forest with cross-flow rules. The model is trained on a 500,000-row sample of CICIDS2017; dataset test performance does not guarantee performance on a new network.

01 / CAPTURE

Packets become flows.

Packets in both directions are grouped into conversations. A flow closes on TCP teardown or expires after 120 seconds.

02 / CLASSIFY

Four features. One verdict.

Duration, forward packet count, forward payload bytes and average packet size feed the binary detector. A separate classifier names only attack types that passed a measured precision gate.

03 / CORRELATE

The pattern comes into focus.

Rules look for distinct ports, distinct hosts and regular connection intervals. Legitimate scanners, telemetry and update checks can also trigger these patterns.

2 / 1,029

The model's blind spot became the lesson.

On the bundled scan, only two conversations were model flags. The behaviour layer detected the wider scan pattern. The numbers and limitations are documented in the repository.
