Guardian
connecting

Know what your network is actually doing.

Guardian captures live packets, groups them into flows, and scores each one against a random forest trained on 2.8 million labelled records. A second layer watches the pattern across flows, where port scans and beacons hide.

Flows are scored on the four features computable from raw packets: duration, packet count, total bytes and average packet size. Attack types are named only where the model measured precise enough to trust. Scans, sweeps and beacons are found across flows instead, because no single flow contains the evidence. Live capture needs administrator access to a network interface, so run uvicorn src.api.main:app locally to enable it.
